# ADR-021: SSH 接続先・tmux ネスト状態の視覚的インジケーター

## ステータス

採用済み

## コンテキスト

SSH 先にいるかローカルにいるかが視覚的に判別しづらい。また、tmux ネスト時にパススルーモードが有効かどうかも分かりづらい。現状、以下の問題がある：

1. **fish プロンプトにホスト名が表示されない** — `fish_prompt.fish` は CWD と Git 情報のみ表示しており、`SSH_CONNECTION` や `SSH_TTY` 環境変数を参照していない。ローカルと SSH 先で同じ見た目のプロンプトが表示される。
2. **tmux ステータスバーに SSH インジケーターがない** — ステータスバーはセッション名・Git ブランチ・タイムスタンプのみ。リモート tmux 内でもローカルと同じ外観。
3. **パススルーモードの表示が不十分** — `tms` 関数や F12 キーでパススルーモードに入ると、ローカル tmux のステータスバー背景が暗いグレー（#444444）に変わるが、背景色の微妙な変化のみでテキスト表示がなく、パススルー中かどうかが一目で判別しづらい。リモート tmux セッション内では「ここが SSH 先である」という表示もない。

結果として、複数のターミナルやペインを使い分けている際に、どのペインが SSH 先かを誤認するリスクがある。また、パススルーモードの ON/OFF 状態が分かりづらいため、キーバインドが意図した tmux レイヤーに届いているか確信が持てない。

## 設計案

### 案 1: fish プロンプトに SSH インジケーターを追加

`fish_prompt.fish` で `SSH_CONNECTION` 環境変数を検出し、SSH 接続時にユーザー名@ホスト名をプロンプトに表示する。

- 利点: tmux に依存しない。SSH 先で tmux を使わない場合でも表示される
- 実装: `set -q SSH_CONNECTION` で分岐し、プロンプトの先頭にホスト名セグメントを追加

### 案 2: tmux ステータスバーに SSH インジケーターを追加

`tmux.conf` のステータスバーで `SSH_CONNECTION` を参照し、SSH 接続時にホスト名やアイコンを表示する。

- 利点: 常時表示されるため見逃しにくい
- 実装: `#{?SSH_CONNECTION,#H ,}` 等の tmux 条件式をステータスバーに追加

### 案 3: パススルーモードのインジケーターを強化

現在の `bg=#444444` だけでなく、ステータスバーにテキスト（例: `[PASSTHROUGH]` や `[REMOTE]`）を追加し、パススルー中であることを明示する。

- 利点: 背景色の微妙な変化だけでなくテキストで状態が分かる
- 実装: `tmux.local.conf.example` の F12 バインドで `status-left` にテキストを追加

### 案 4: 案 1 + 案 2 + 案 3 の併用

プロンプト・ステータスバー・パススルーインジケーターの全てで状態を表示する。冗長だが確実。

### 変更が必要なファイル

| ファイル | リポジトリ | 変更内容 |
|---------|----------|---------|
| `configs/fish/functions/fish_prompt.fish` | dotfiles | SSH 検出 + ホスト名セグメント追加 |
| `configs/tmux/tmux.conf` | dotfiles | ステータスバーに SSH インジケーター追加 |
| `configs/tmux/tmux.local.conf.example` | dotfiles | F12 パススルー時にテキストインジケーター追加 |
