# ADR-026: tmux パススルーモードの UI 改善

## ステータス

採用済み

## コンテキスト

tmux ネスト構成（ローカル + リモート）でパススルーモードを使用する際、以下の2つの UI 課題がある。

### 課題1: ステータスバーの表示が実装寄り

パススルーモード ON 時にステータスバーに `[PASSTHROUGH]` と表示されるが、これは実装の仕組みを示しているだけで、ユーザーが本当に知りたい「今どちらの tmux を操作しているか」が直感的に分からない。

### 課題2: SSH 以外の window でパススルーが有効化できてしまう

現状 F12 キーは全 window で使用可能だが、パススルーモードは SSH 経由のリモート tmux 接続時にのみ意味がある。SSH window 以外で有効にしても転送先がなく、ローカル tmux が操作不能になるだけで混乱を招く。

### 課題3: ネスト接続時のステータスバー重複

SSH 接続でリモート tmux にネストすると、画面下部にローカルとリモート両方のステータスバー（各2行、計4行）が表示される。パススルーモード中はローカル tmux のステータスバーは操作対象外であり、表示する意味がほぼない。画面の有効面積を圧迫するだけでなく、どちらのステータスバーを見ればよいか混乱する。

現状のパススルーモード時の表示:
```
├─────────────────────────────────┤  ← リモート separator (status-format[0])
│ REMOTE: work │ 1:fish  2:vim   │  ← リモート ステータスバー
├─────────────────────────────────┤  ← ローカル separator (status-format[0])
│ [PASSTHROUGH] main │ 1:ssh ... │  ← ローカル ステータスバー
```

## 設計案

### 案1: ステータスバー表示の改善 + パススルー時にローカルステータスバーを非表示（採用）

3つの変更を組み合わせる:

1. **ステータスバー表示の改善**: `[PASSTHROUGH]` を `LOCAL` / `REMOTE` に変更し、操作対象のレイヤーを明示する
2. **パススルー時のローカルステータスバー非表示**: パススルーモード ON 時に `set status off` でローカルのステータスバーを完全に非表示にし、リモートのステータスバーのみ表示する
3. **F12 手動トグルの廃止 → SSH 自動切り替え + F12 復帰のみ**: SSH 接続時に `tms` / `ssh` ラッパーが自動でリモートモードに切り替える。F12 は SSH window 内でのみ LOCAL に戻す手段として残す。SSH 以外の window では F12 バインドを削除する

パススルー ON 時:
- ローカル tmux: `set status off`（非表示）
- リモート tmux: 通常通り表示（ユーザーはリモートのステータスバーだけを見る）

パススルー OFF 時:
- ローカル tmux: `set -u status`（通常表示に復帰）

ステータスバー非表示により `LOCAL` / `REMOTE` 表示はパススルー OFF 時（= LOCAL モード）のみ表示されることになるが、パススルー ON 時はリモート tmux のステータスバーがそのまま「リモート操作中」のインジケーターとして機能するため、追加表示は不要。

### 変更が必要なファイル

| ファイル | リポジトリ | 変更内容 |
|---------|----------|---------|
| `configs/tmux/tmux.conf` L128-147 | dotfiles | F12 の root テーブルバインド（パススルー ON）を削除。off テーブルの F12（LOCAL 復帰）は維持。`set status off` / `set -u status` を追加 |
| `configs/fish/functions/__tmux_passthrough_on.fish` | dotfiles | `set status off` を追加、status-left の `[PASSTHROUGH]` 表示を削除 |
| `configs/fish/functions/__tmux_passthrough_off.fish` | dotfiles | `set -u status` を追加 |
