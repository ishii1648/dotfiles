# ADR-024: tmux ネスト環境での remote/local セッション間移動

## ステータス

Draft

## コンテキスト

ADR-022 により SSH 実行時にリモート先の tmux セッションへ自動アタッチされるようになった。しかし、リモート tmux セッションにアタッチした状態では、ローカル tmux セッションへ移動する手段がない。

現状の問題:
- リモート tmux セッション内でローカル tmux のキーバインド（`prefix + s` 等）を押しても、リモート tmux が先にキャプチャしてしまう
- ローカル tmux セッションに戻るには、リモート tmux をデタッチまたは SSH 接続を切断する必要がある
- 複数のリモートホストに接続している場合、ホスト間の移動も同様に不便

ADR-023 で明文化したネスト構成のコストの一つであり、パススルーモード（F12）で inner/outer を切り替える仕組みは既にあるが、セッション一覧の表示・選択にはワンステップ多い。

## 設計案

1. **パススルーモード解除 + セッション選択のワンキー化**: F12 でパススルー解除後に自動で `choose-tree` を表示する専用キーバインドを追加
2. **ローカル tmux への直接キーバインド**: パススルーモードに関係なくローカル tmux に直接送信されるキーバインド（例: `S-F12` や別の未使用キー）を設定し、ローカル tmux のセッション一覧を表示
3. **tmux popup によるセッション切替 UI**: ローカル tmux 側で popup ウィンドウを使い、ローカル・リモート両方のセッションを統合表示する

### 変更が必要なファイル

| ファイル | リポジトリ | 変更内容 |
|---------|----------|---------|
| `configs/tmux/tmux.conf` | dotfiles | セッション切替用キーバインド追加 |
| `configs/tmux/tmux.remote.conf.example` | dotfiles | リモート側の対応キーバインド追加（必要に応じて） |
